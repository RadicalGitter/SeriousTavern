# SeriousTavern

The personal `radicalgitter/SeriousTavern` distribution tracks SillyTavern's
release branch while adding a reproducible, profile-oriented roleplay bundle.
Its extension lock, memory authority contract, and bootstrap instructions live
in [serious-tavern/README.md](serious-tavern/README.md).

No chats, keys, models, user settings, or third-party extension source are
committed to the fork.
